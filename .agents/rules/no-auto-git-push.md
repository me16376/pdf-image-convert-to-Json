# Strict Rule: NEVER Run `git push` Automatically

## CRITICAL DIRECTIVE:
- **NEVER run `git push` autonomously or automatically under ANY circumstance.**
- Even if all work, tests, and conversions are completed, **DO NOT run `git push`**.
- Only and ONLY execute `git push` if the user explicitly writes a direct instruction to push (e.g., "git push koro", "push to git", "push to remote").
- Local commits (`git commit`) are permitted, but remote pushes (`git push`) are strictly forbidden without explicit user command.
